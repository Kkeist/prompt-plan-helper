# What to write in each part

Write the result that is wanted. No code knowledge is needed. The writing is the same for a website, a phone app, a game or desktop software.
The examples describe an invented pomodoro timer and only show how to write.

## How to fill it in

- Fill it in directly, or describe what is wanted and let the AI write a full draft in one pass; anything missing is marked in place as "TBD: what is missing".
- The plan can be changed at any time. Work starts only when nothing is TBD and the plan is confirmed.
- What to build first and how to build it are decided by the AI and submitted as build notes for confirmation. They are not written in the plan.

## 1 Basics

| Field | What to write | Example |
|---|---|---|
| Description | The thing being made, in one or two sentences | A timer that counts 25 minutes of work and 5 minutes of rest, over and over |
| Intended users | Who uses it, and when | People who need to focus, sitting at a computer |
| Outcome | The result after using it | They know how many rounds they focused today |

## 2 Usage flow

| Field | What to write | Example |
|---|---|---|
| Usage flow | One line each: the user does something → sees something → does the next thing | Start a round: click Start → see the countdown → hear a sound when time is up |

## 3 Pages

One block per page; more can be added. A phone screen, a web page or one view in a game each counts as a page.

| Field | What to write | Example |
|---|---|---|
| Page purpose | What the user does here | Watch the countdown, start or pause it |
| Page elements | One line per item: name: what it is; what happens when it is clicked or touched | Start button: starts the countdown; turns into Pause |
| Entry point | Where the user comes from | It is the first thing they see |

## 4 Features

One block per feature; more can be added. A feature is one thing it can do.

| Field | What to write | Example |
|---|---|---|
| Feature description | What this one thing is, in one sentence | Counts down the set number of minutes |
| Acceptance criteria | One line per situation: a situation: what should happen | Set 25 minutes and click Start: it drops by one each second and alerts at 0 |
| Constraints | Number ranges and what must not happen | Minutes must be from 1 to 120 |
| Progress | Not started, In progress or Done; the AI updates it when finished | Not started |
| Issues | Problems found while building, one per line; marked "Fixed" once repaired | The number keeps counting after Pause |

## 5 Information to keep

| Field | What to write | Example |
|---|---|---|
| Information | One per line: name: what it contains; whether it is kept for next time | Settings: work minutes, rest minutes; kept |

## 6 Style

| Field | What to write | Example |
|---|---|---|
| Visual style | Style, colours, mood | White background, simple, like a notebook |
| References | A product or look to refer to; a name is enough | Like the timer that comes with the system |
| Exclusions | Content that must never appear | No ads, no pop-ups that interrupt |

## 7 Environment and requirements

Fields with options can take several; anything not listed goes under "Other requirements".

| Field | What to write | Example | Options |
|---|---|---|---|
| Platform | The platforms it is used on | Web, phone app | Web, phone app, desktop software, mini program, command line, game console |
| Application type | The kind of thing it is | Tool | Tool, game, content display, admin panel, social, other |
| Interface languages | The languages the interface needs | Chinese, English | Chinese, English, other |
| Asset sources | Who supplies images, texts and sounds, or whether the AI draws or writes them | A free sound effect; the AI draws the icon |  |
| Accounts and sign-in | Whether users have to register | Not needed | Not needed, needed |
| Other requirements | Other additions | None |  |

# What to write in each part

Write what you want, in plain words; no code knowledge needed. It works the same whether you are making a website, a phone app, a game, desktop software or anything else.
The examples are about an invented "pomodoro timer" and only show how to write.

## How to fill it in

- You can fill it in yourself, or just say what you want and let the AI write a full draft in one go, writing "TBD: what is missing" in place.
- The plan can be changed at any time. Work starts only when nothing is TBD and you have confirmed it.
- What to build first and how to build it are decided by the AI, who writes it up for you to confirm. You do not write that.

## 1 What it is

| Field | What to write | Example |
|---|---|---|
| What it is | What is being made, one or two sentences | A timer that counts 25 minutes of work and 5 minutes of rest, over and over |
| Who it is for | Who uses it, and when | People who need to focus, sitting at a computer |
| What they get from it | What the user ends up with | They know how many rounds they focused today |

## 2 How it is used

| Field | What to write | Example |
|---|---|---|
| Way of using | One line each: the user does something → sees something → does the next thing | Start a round: click Start → see the countdown → hear a sound when time is up |

## 3 Screens

One block per screen; you can keep adding. A phone screen, a web page or one view in a game each counts as a screen.

| Field | What to write | Example |
|---|---|---|
| What this screen is for | What the user does here | Watch the countdown, start or pause it |
| What is on the screen | One line per thing: name: what it is; what happens when clicked or touched | Start button: starts the countdown; turns into Pause |
| How the user gets here | Where they come from | It is the first thing they see |

## 4 Features

One block per feature; you can keep adding. A feature is one thing it can do.

| Field | What to write | Example |
|---|---|---|
| What it does | What this one thing is, in one sentence | Counts down the set number of minutes |
| Done when | One line per situation: a situation: what should happen | Set 25 minutes and click Start: it drops by one each second and alerts at 0 |
| Limits | Number ranges, what must not happen | Minutes must be from 1 to 120 |
| Progress | Not started, In progress or Done; the AI changes it when finished | Not started |

## 5 Information to remember

| Field | What to write | Example |
|---|---|---|
| Information | One per line: name: what it contains; whether it should still be there next time | Settings: work minutes, rest minutes; kept |

## 6 Look and requirements

| Field | What to write | Example |
|---|---|---|
| Where it is used | Phone, computer, web, game console, or something else | Phone and computer |
| Look and feel | The style, colours, mood you want | White background, very simple, like a notebook |
| Anything to refer to | Something whose look you like; a name is enough | Like the timer that comes with the system |
| Must not have | Things that must never appear | No ads, no pop-ups that interrupt |
| Anything else | Anything else you thought of | Chinese and English |

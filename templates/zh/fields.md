# 每一块写什么

写的是想要的结果，不需要代码知识。无论是网页、手机应用、游戏还是桌面软件，写法相同。
示例围绕一个虚构的番茄钟，只用于说明写法。

## 填写方式

- 可以自己填写，也可以只描述想做的东西，由 AI 一次写出完整草稿，缺少的内容在原位标注「待补：缺什么」。
- 计划书可以随时修改。没有「待补」并确认后才开始制作。
- 先做什么、如何实现由 AI 决定，写成做法后提交确认，不需要在计划书中填写。

## 1 基础信息

| 字段 | 写什么 | 例 |
|---|---|---|
| 项目描述 | 要做的东西，一两句话 | 一个计时器，工作 25 分钟、休息 5 分钟，轮流提醒 |
| 使用对象 | 使用的人，以及使用的时机 | 需要专心做事的人，坐在电脑前的时候 |
| 使用结果 | 使用之后得到的结果 | 知道今天专心做了几轮 |

## 2 使用流程

| 字段 | 写什么 | 例 |
|---|---|---|
| 使用流程 | 每种用法一行：用的人做什么 → 看到什么 → 再做什么 | 开始一轮：点「开始」→ 看到倒计时 → 时间到听到提示音 |

## 3 页面

每个页面一块，可以继续添加。手机上的一屏、网页的一页、游戏中的一个画面，都算一个页面。

| 字段 | 写什么 | 例 |
|---|---|---|
| 页面用途 | 用的人在这里做什么 | 查看倒计时，开始或暂停 |
| 页面元素 | 页面上的每一样东西，一行一个：名字：它是什么；点击或触碰后会怎样 | 开始按钮：开始倒计时；点击后变成「暂停」 |
| 进入方式 | 从哪里进入 | 一打开就是它 |

## 4 功能

每个功能一块，可以继续添加。功能是它能完成的一件事。

| 字段 | 写什么 | 例 |
|---|---|---|
| 功能说明 | 这件事是什么，一句话 | 按设定的分钟数倒计时 |
| 验收标准 | 每种情况一行：某种情况：应该出现什么 | 设成 25 分钟点开始：每秒减一，到 0 时提示 |
| 限制条件 | 数字范围，以及不允许出现的情况 | 分钟数只能是 1 到 120 |
| 进度 | 未做、进行中、已完成，AI 完成后自动更新 | 未做 |
| 问题 | 制作过程中发现的问题，一行一个，修好后标注「已修」 | 点暂停后数字仍在走 |

## 5 需要保存的信息

| 字段 | 写什么 | 例 |
|---|---|---|
| 信息 | 每种一行：名字：包含什么；下次打开是否保留 | 设置：工作分钟数、休息分钟数；保留 |

## 6 风格

| 字段 | 写什么 | 例 |
|---|---|---|
| 视觉风格 | 风格、颜色、气氛 | 白底、简洁、像笔记本 |
| 参考对象 | 希望参考的产品或样式，写名称即可 | 像系统自带的计时器 |
| 禁止出现 | 一定不能出现的内容 | 不要广告，不要打断操作的弹窗 |

## 7 使用环境与要求

可选项的字段可以多选，选项里没有的写在「其他要求」里。

| 字段 | 写什么 | 例 | 可选项 |
|---|---|---|---|
| 使用平台 | 在哪些平台上使用 | 网页、手机应用 | 网页、手机应用、电脑软件、小程序、命令行、游戏机 |
| 应用类型 | 属于哪一类 | 工具 | 工具、游戏、内容展示、管理后台、社交、其他 |
| 界面语言 | 界面需要提供的语言 | 中文、英文 | 中文、英文、其他 |
| 素材来源 | 图片、文字、声音分别由谁提供，或交给 AI 绘制、撰写 | 提示音使用免费素材，图标由 AI 绘制 |  |
| 账号与登录 | 使用者是否需要注册 | 不需要 | 不需要、需要 |
| 其他要求 | 其他补充内容 | 无 |  |

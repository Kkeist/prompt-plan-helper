# 计划书：prompt 计划书助手

状态：整理中　　更新：2026-10-15

## 1 基础信息

项目描述：新项目计划书的书写模板。在页面里按提示填写，AI 据此制作，制作过程中可以随时查看进度和问题。
使用对象：用 AI 制作东西的人，不要求懂代码，做的可能是网页、应用、游戏或其他。
使用结果：一份 AI 可以直接照着做的计划书，以及开始制作后独立出来、随时更新的功能清单。

## 2 使用流程

写计划书：把想法交给 AI → AI 写出计划书 → 在页面里查看并直接修改 → 没有待补并确认后开始制作
自己填：新建空白计划书或查看示例 → 点击每一块，按框内提示填写 → 补完待补 → 确认
看进度：开始制作后打开功能清单 → 看到每个功能的进度和未处理的问题 → AI 完成一个功能后，进度自动更新
写问题：在窗口最下面的输入框写下问题（可以多行），输入 @ 可以换功能，或在网页上打开悬浮窗 → 点提交 → AI 读取并修复
找文件夹：按桌面快捷键 → 屏幕右下角弹出小窗口，列出最近使用的文件夹 → 复制地址在命令行中打开，或打开它的计划书
标记要改的位置：在制作中的页面上打开小窗 → 选取元素、框选区域或记录当前页面 → 写一句说明 → 复制给 AI

## 3 页面

### 3.1 计划书页

页面用途：开始制作之前是计划书，开始制作之后另有一份功能清单，初始计划书不再改。查看和修改内容，查看每个功能的进度和问题。
页面元素：
- 标签：每个打开的项目一个标签，可以关闭，也可以再添加；桌面版多一个「最近」标签
- 项目情况或功能清单：每个功能做什么、进度、未处理的问题；功能清单只列已经做出来的功能，还没做的收起在下面；点功能名选中它，在窗口最下面的输入框写问题
- 每一块内容：点击后变成大填写框，点击框外保存；框内显示这一块该写什么和示例
- 待补数量：点击后跳到下一处
- 确认并开始：没有待补时确认
- 语言：下拉选择中文或 English
- 更多：目录、复制全文、导出、查看示例、新建、导入、连接文件夹、下载桌面版
进入方式：打开网页；或在「最近」里点击某个文件夹的「打开计划书」

### 3.2 最近

页面用途：列出最近使用的文件夹，一键打开计划书或复制地址。
页面元素：
- 正在使用的文件夹：最近有活动的，标注「使用中」
- 最近使用的、连接过的文件夹：每个显示完整地址和进度
- 打开计划书：在新标签中打开
- 地址文字：点击复制完整地址，没有单独的复制按钮
- 新建计划书：先写计划书，写好以后再存进文件夹
- 新建文件夹：选择放在哪里，起名字，创建后打开
- 选择别的文件夹：弹出系统的文件夹选择窗口
- 把文件夹直接拖进窗口，也可以打开
进入方式：桌面快捷键，或计划书页里的「最近」标签

### 3.3 标记要修改的位置（小悬浮窗）

页面用途：在制作中的页面上标记要修改的位置，生成一段可以直接发给 AI 的文字。
页面元素：
- 选取元素：点击页面上的一个元素，记录它的位置、文字和样式
- 区域截图：在页面上框选一块区域，保存为图片
- 当前页面：一次记录当前页面的地址、标题、窗口大小、可见的标题和按钮，并保存整页截图
- 修改说明：写明需要修改的内容
- @ 功能：装了浏览器扩展并打开过桌面小窗口时，选择问题属于哪个功能，输入 @ 可以切换，计划书也可以切换
- 记到计划书：把问题直接记进所选功能下面
- 复制文字、复制截图：复制出去发给 AI
进入方式：制作中的页面里的薯片按钮，或 Alt+Shift+S

## 4 功能

### 4.1 查看与修改

功能说明：把计划书显示成可读的页面，点击任何一块即可直接修改，随时允许修改。
验收标准：
- 点击一块，改完点击框外：保存并显示
- 添加页面或功能：填写名称，为空或重名时提示，成功后出现一组空字段
- 删除页面或功能：可以撤销
- 开始制作之后：功能清单是独立的一份，后面的修改和进度都记在功能清单里；初始计划书保持确认时的样子，只读
- 有固定选项的字段（使用平台、应用类型、界面语言、账号与登录）：编辑时在填写框上方给出可点选的选项，可以多选
限制条件：页面名和功能名不重名；编号只增不重排
进度：已完成

### 4.2 项目情况与功能清单

功能说明：显示每个功能做什么、做到哪一步；开始制作之后生成独立的功能清单，可以在功能下记录问题。
验收标准：
- 功能块里写了进度：按未做、进行中、已完成显示，并统计各有几个
- AI 或其他编辑器修改了计划书文件：页面几秒内自动更新，不需要刷新
- 点击进度：在三种之间切换并写回计划书
- 开始制作之后：出现「功能清单」和「初始计划书」两个页签，打开先看功能清单
限制条件：没写进度的按未做计算
进度：已完成

### 4.3 写问题

功能说明：在功能清单里给功能记录问题，AI 读取后逐条处理，处理状态在页面上实时显示。
验收标准：
- 窗口最下面的输入框：用列表写问题，点「添加一条」或回车加一条，每条可以 @ 多个功能，写完随时可以改，点提交记到所选功能下面
- 添加：问题写入各自功能块的「问题」下，带日期；一条问题 @ 了几个功能，就记到每个功能下；记问题、改进度不改变已通过的状态
- 状态：每条问题有待处理、处理中、已修三种，点击切换；AI 处理时页面实时变化，已修的留在列表里并划掉
- 点击问题文字：直接修改和补充
- 删除：可以撤销
限制条件：问题只记文字，不带图片
进度：已完成

### 4.4 标签页

功能说明：一个窗口里同时打开多个项目，用标签切换；桌面版多一个「最近」标签。
验收标准：
- 在「最近」里点击打开计划书：新开一个标签，不覆盖别的
- 关闭标签：不丢内容，之后可以从「更多」里再次打开
- 刷新页面：打开的标签和当前标签都保留
限制条件：标签放不下时换行，每个标签都完整显示
进度：已完成

### 4.5 最近的文件夹

功能说明：列出最近使用的文件夹，不用每次手动查找；复制地址方便在命令行中打开。
验收标准：
- 桌面快捷键打开：最近使用的文件夹排在最前，点击即可打开它的计划书
- 每个文件夹的地址文字点击即可复制；点框里别处打开它的计划书
- 新建计划书：直接得到空白计划书，状态行有「保存到文件夹」，可选已有文件夹或新建文件夹；文件夹里已有计划书时让用户选用哪一份，不直接覆盖
- 新建文件夹：先选位置，再填名称，重名或名称不合法时说明原因
- 拖入文件夹：按名字和里面的文件找到它的地址并打开；找不到地址时也能打开和保存，只是不能复制地址，并给出说明
- 页面里修改了计划书：自动保存进文件夹；文件夹里被修改：自动读入页面；两边都改了：弹窗让用户选择
限制条件：「使用中」按最近的活动推测，不一定是当前窗口；没有桌面版时使用浏览器自带的文件夹选择，仅支持电脑版 Chrome 和 Edge
进度：已完成

### 4.6 标记要修改的位置（小悬浮窗）

功能说明：标记页面上要修改的位置、框选区域、记录当前页面，合成一段可以直接发给 AI 的文字。
验收标准：
- 选取元素：记录它的路径、文字、尺寸和样式
- 区域截图：窗口先隐藏，拖动选择区域，保存为图片；装了浏览器扩展时使用真实截图，否则标注为伪截图
- 当前页面：一次记录地址、标题、窗口大小、可见的标题和按钮文字、最近的报错，并保存整页截图
- 复制文字：文字里带页面地址、窗口大小、元素、样式、修改说明和报错
- 记到计划书：问题加上页面地址和元素，写进所选功能的「问题：」下面；桌面小窗口没打开时说明原因，仍可复制文字
- 页面自己引入了脚本又装了扩展时，只留一个悬浮窗
限制条件：伪截图里跨域的图片和字体显示为空白；记到计划书需要浏览器扩展和打开过的桌面小窗口
进度：已完成

### 4.7 导入、导出、复制和示例

功能说明：把计划书带进、带出页面，并提供示例。
验收标准：
- 复制全文、复制提示词：浏览器不允许写入剪贴板时，弹出全文框，手动复制
- 导出：得到 md 文件，文件名带日期时间
- 导入：整份替换，可以撤销；识别不出格式时原文放入「未识别」
- 查看示例：载入当前语言的示例，就是这份计划书本身
限制条件：导出再导入内容不变；没填的字段导出时写「待补：缺……」
进度：已完成

### 4.8 确认检查

功能说明：统计还有几处待补，确认后把状态改成已通过。
验收标准：
- 还有待补时点击确认：提示数量，状态不变
- 没有待补时点击确认：状态变成已确认，还没开始制作时仍然是更新计划书
限制条件：确认之前不开始制作
进度：已完成

### 4.9 桌面版和快捷键

功能说明：不用先打开网站，按快捷键就在屏幕右下角弹出小窗口；网页里可以下载桌面版。
验收标准：
- 桌面版是一个 exe：双击后在托盘待命，快捷键 Ctrl+Alt+S 弹出小窗口
- 小窗口贴在屏幕右下角
- 网页的「更多」里有「下载桌面版」，从自己的站点下载
- 没有桌面版时，用 start.bat 启动，用 start-debug.bat 调试
限制条件：仅限 Windows；exe 没有数字签名，第一次运行系统会提示
进度：进行中

### 4.10 中英文

功能说明：界面、模板、字段说明、示例、提示词都有中文和英文。
验收标准：
- 界面语言用下拉选择，默认跟随浏览器
- 新建的计划书按当前界面语言使用对应模板
- 中文和英文的计划书都能读取，都能统计待补和进度
限制条件：文字放在每种语言各一个的语言文件里，代码里只有键；键缺少或没人用、代码里出现中文字符串时构建失败
进度：已完成

### 4.11 AI 说明和命令行

功能说明：让 AI 不打开网页就能检查计划书、更新进度、处理问题。
验收标准：
- 检查：输出状态、待补位置、重名；没有待补时退出码为 0
- 更新进度：按功能名写回计划书
- 问题：列出所有问题（带序号和状态），按序号把一条标成处理中或已修
- AI 说明：包含整理计划书、更新进度、处理问题、默认解耦的架构
进度：已完成

### 4.12 扩展里的真实截图

功能说明：装了浏览器扩展后，截图使用浏览器自带的真实截图。
验收标准：
- 在 Chrome 里点击区域截图：附图标注为「截图」
限制条件：需要在真实的 Chrome 里确认一次
进度：进行中

## 5 需要保存的信息

- 计划书：一份 md，含状态；刷新后保留；可以有多个项目
- 打开的标签：哪些项目开着、当前是哪个；刷新后保留
- 文件夹授权和连接历史：连接过的文件夹；刷新后保留
- 悬浮窗位置：窗口和按钮的位置；刷新后保留

## 6 风格

视觉风格：黑白、简洁、白底，内容放在中间一条列里，窗口小的时候不拥挤
参考对象：无
禁止出现：不要打断操作的弹窗，不要出现必须懂代码才能理解的内容，不要使用虚线

## 7 使用环境与要求

使用平台：网页、电脑软件（仅限 Windows）
应用类型：工具
界面语言：中文和英文
素材来源：图标用代码绘制
账号与登录：不需要
其他要求：架构默认解耦，模块之间只通过接口通信
